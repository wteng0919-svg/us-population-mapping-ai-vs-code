### 写提示词的三条经验

1. **给绝对路径**。模型没有文件浏览器，路径写全（含空格、中文）最稳。
2. **给验收标准**。“比例尺、图例、指北针、标题、命名、格式、放哪个文件夹”一次说完，比来回补快得多。
3. **让它自查**。明确要求“检查字段统计 / 列出未匹配”，它才会去调 `getFieldStatistics`，否则很容易只交图不交数。
